# GPX folder

Place GPX files here for each route. Use lowercase, hyphenated filenames, e.g.:

- mt-babag-main.gpx
- sirao-peak-main.gpx
- mount-naupa-village.gpx
- manunggal-classic.gpx
- mount-mago-forest.gpx
- kapayas-summit.gpx

Also fill `sources.json` with route metadata and source URLs so the generator can produce SQL inserts and a summary.
